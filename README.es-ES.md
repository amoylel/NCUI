

# NCUI
Un marco de interfaz de usuario para escritorio similar a Electron, basado en Duilib+CEF++NodeJs. Compatible con CEF 2272 y versiones posteriores, Node 4x y versiones posteriores, y apto para sistemas Windows XP y superiores.
